# Contributing to SceneCraft
Thanks for your interest in contributing to SceneCraft!

SceneCraft prioritizes performance and a smooth client experience. Contributions that help make recording, replaying, rendering, and using the client smoother are especially welcome.

## Keep It Focused
Please aim for **one specific goal per pull request (PR)**. Keep changes focused on that goal instead of bundling unrelated work together.

## Prioritize Performance
When working on a contribution, consider its impact on client performance and smoothness. Avoid unnecessary work, stuttering, blocking the client, or resource usage when practical.

Performance improvements are welcome, but they should preserve correct behavior and stability. If you claim a performance improvement, explain what changed and share measurements or observations when available.

## Before Opening a PR
Briefly explain:
- What specific goal the PR addresses.
- What you changed.
- How you tested it, if applicable.
- Any relevant performance impact.
  
Thanks for helping make SceneCraft better!
